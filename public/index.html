Corridor Dynamics & Architectural Overview

Comprehensive operational insights into traffic flow periodicity, weather sensitivity, and modeling strategy.

⏰

Bimodal Diurnal Peak Commute

Traffic volume on Interstate 94 exhibits pronounced daily commuter cycles with two distinct peaks:

  • Morning Peak: Surges sharply between 07:00 and 08:00 AM (averaging ~4,900 to 5,200 veh/hr).
  • Evening Peak: Maximum congestion occurs from 16:00 to 17:00 PM (averaging ~5,400 to 5,800 veh/hr).
  • Overnight Drop: Low trough from 01:00 to 03:00 AM (< 500 veh/hr), offering ideal maintenance windows.
📅

Weekday Commuter vs. Weekend Plateau

Weekday volume displays twin peaks, whereas Saturday and Sunday traffic displays a smooth, single plateau peaking between 12:00 PM and 16:00 PM at ~4,500 veh/hr.

  • Weekday Mean: ~3,480 veh/hr across working hours.
  • Weekend Mean: ~2,720 veh/hr, shifted toward midday recreational movement.
  • Holiday Impact: Major holidays reduce commute demand by 38% on average.
🌦️

Environmental & Weather Modulation

Adverse weather conditions decrease speed, increase headway spacing, and suppress non-essential travel:

  • Precipitation: Heavy rainfall (> 10 mm/hr) suppresses vehicle flow by 9% to 15%.
  • Snow Conditions: Winter blizzards reduce average speeds and volume up to 25%.
  • Temperature Extremes: Sub-zero Minnesota winter temps (-20°C) dampen overall transit.
🧠

Chronological ML & Feature Pipeline

Rigorous leakage-free data science pipeline preserving chronological sequence:

  • Strict Train/Test Partition: First 80% (38,549 rows) for training, latest 20% (9,638 rows) for validation.
  • Cyclical Trigonometry: Sine and cosine transforms on hour, day-of-week, and month.
  • Zero Data Leakage: Scalers and encoders fit solely on training data.

Model Robustness & Leakage Safeguards

  • Strict Temporal Split: Chronological order preserved (Training: 2012–2017, Testing: 2017–2018). Random shuffling was forbidden to mirror real-world production forecasting.
  • Zero Preprocessor Leakage: Standard scaler for temperature/rain and One-Hot encoders fit exclusively on training data.
  • Physically Bounded Outputs: Traffic volume is strictly bounded non-negative (>= 0) and capped at physical lane capacity.
  • Missing & Anomaly Imputation: Extreme sensor failures (e.g. 0 Kelvin temp) automatically imputed using training set medians.

One-Click Vercel & Cloud Deployment Guide

How to deploy this complete traffic analytics application to Vercel and Streamlit Cloud.

▲ Vercel

Deploy to Vercel (CLI or GitHub)

This repository is configured with vercel.json, static assets in public/, and a serverless API in api/predict.py.

1
Option A: One-Command Terminal Deployment

Run the Vercel CLI from your project directory in PowerShell or Bash:

npx vercel

Press Enter on default prompts. Vercel will build and output your production live URL.

2
Option B: Git Push to Vercel Dashboard

Initialize git, push to your GitHub / GitLab account, and import the repository at vercel.com/new.

git init git add . git commit -m "Deploy Urban Traffic Flow Optimization to Vercel" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/UrbanTrafficFlowOptimization.git git push -u origin main
👑 Streamlit Cloud

Deploy Python GUI (app.py)

Streamlit requires continuous WebSockets. Host the full Python GUI on Streamlit Community Cloud (free forever):

1
Push Repository to GitHub

Ensure requirements.txt, app.py, and models/ are committed.

2
Connect to Streamlit Cloud

Go to share.streamlit.io, select your repository, specify Main file path as app.py, and click Deploy.

3
Run Locally Anytime
streamlit run app.py
